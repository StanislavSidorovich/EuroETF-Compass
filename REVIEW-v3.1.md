## Найдено, но НЕ сделано (по приоритету)
1. **«Живых» цен на GitHub Pages нет вообще.** Все 4 шлюза мертвы: `corsproxy.io` → 403 (`keyless_legacy_url`), `codetabs` / `allorigins` → таймаут, прямой Yahoo → CORS. Бейдж «35/35 база» честно это показывает, но кнопка «Обновить» и «Live» в тексте вводят в заблуждение. Решение: GitHub Action по расписанию (раз в день) тянет котировки Yahoo на сервере и коммитит `public/data/quotes.json`; приложение читает его первым. Для произвольных тикеров — бесплатный Cloudflare Worker как прокси.
2. **Тёмная тема по умолчанию + светлая через `!important`-оверрайды** (~400 строк в `index.css`). Хрупко: каждый новый класс надо дублировать. Лучше перейти на CSS-переменные.
3. **Слишком много слоёв до калькулятора:** шапка → 4 карточки → бегущая лента → цитата + «Сила времени» → предупреждение → шаги. Главное действие (бюджет → портфель → результат) на втором экране. Предложение: цитату и «Силу времени» свернуть по умолчанию.
4. **Один компонент — до 73 КБ** (`EtfSelector`, `InvestmentCalculator`, `TaxFilingToolkit`). Пора дробить, пока не стало трудно править.
5. **Налоговые данные** (Португалия: скидки за срок владения, Anexo J, Германия, Нидерланды Box 3) — перед тем как показывать человеку как руководство к действию, сверить с официальными источниками (AT, BZSt, Belastingdienst). Это генерировал ИИ.
6. Бандл > 500 КБ — code-splitting вкладок через `React.lazy`.
